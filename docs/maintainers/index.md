# Maintainers

How v2t is built, tested and shipped. You only need this page to contribute.

| Task | Command |
|---|---|
| Set up | `uv sync` |
| Lint | `just lint` |
| Fast checks (no models, microphone or permissions) | `just check` |
| Build the wheel and sdist | `just build` |
| Build the docs | `uv run --only-group docs zensical build --strict` |
| Benchmark models on this Mac | `just bench` |

## Code layout

| Path | Holds |
|---|---|
| `v2t/cli.py` | Every `v2t` verb |
| `v2t/app.py` | The engine: hotkey, recording, the 60 s rule, cleanup, paste |
| `v2t/backends.py` | Parakeet, Whisper and the cleanup engines |
| `v2t/config.py` | `~/.v2t` paths, `config.toml`, history |
| `v2t/native/Voice2Text.swift` | The menu app and the pill, one Swift file |
| `v2t/menubar.py`, `v2t/service.py` | Building the menu app; the login item |
| `assets/logo/` | The logo and app icon, regenerated by the scripts there |
| `utils/` | Maintainer tools: the speech-model grid, cleanup bench, dictation benchmark |

## CI

| Workflow | Runs on | Does |
|---|---|---|
| `check.yml` | every push and pull request | Lock check, lint, smoke tests, wheel and sdist build; Swift type-check on macOS |
| `docs.yml` | docs changes | Strict docs build; deploys to GitHub Pages from `main` |
| `release.yml` | a `v*` tag | Publishes to PyPI, signs and notarises the menu app, updates the cask |

## Release

1. Bump `version` in `pyproject.toml` and add a `CHANGELOG.md` entry.
2. Push a tag `v<version>` that matches it.

There is no approval step: only `v*` tags reach the `release` environment, so pushing the tag is
the release decision. The workflow publishes the engine to PyPI with trusted publishing, attaches the notarised app to
the GitHub Release, and commits the new cask checksum to `main`.

## Benchmarks

- `just bench` writes one file per Mac to `~/.v2t/benchmarks/results/`: transcription speed and
  cleanup latency per model. [benchmarks/README.md](https://github.com/lucharo/voice2text/blob/main/benchmarks/README.md)
  has the options.
- `utils/asr_grid` compares speech models on labelled clip sets: whole-file, streaming, and in
  30 s pieces (`grid.py chunk`), the way v2t transcribes from 60 s.
  `utils/asr_grid/plot_wait.py` draws the wait-vs-length chart on [How it works](../how-it-works.md).
  Each benchmark's README says what it answers, its inputs and how to read the numbers.
- `utils/cleanup_speed` times the cleanup paths against each other.

## Docs

- User pages live in `docs/`; this page is the only maintainer page on the site.
- Release history, qualification evidence and dated audits live in `internal/`, which is in Git
  but never built into the site or packed into the sdist.
- Examples use long flag names (`--last`, not `-n`); only the [CLI reference](../reference/cli.md)
  lists the short ones.
