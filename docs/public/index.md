# voice2text

**Hold a key, talk, let go.** Your words are pasted into your current app.

The default speech and cleanup models run on your Apple Silicon Mac. Model files download on first use.

```bash
uv tool install --python 3.13 voice2text
v2t
```

Grant Microphone and Accessibility permissions, then hold **Fn** to dictate.

[Get started](getting-started.md) covers setup and the optional menu app.
